# V4 · Nav + Sobre mí + divisores (2026-10-25)

Rama: `visual/v4-nav-sobre-mi` (desde `dev`). Cinco tareas con agentes Sonnet, una por vez, cada una con punto de
control. Todo CSS donde fue posible: JS nuevo: ≈ +2,4 KB gzip en total (`about.js` en chunk aparte de 1,5 KB, la pill y el script del header).

## Hecho
1. **Pill del nav con spring** (`Nav.astro`): el fondo activo mide siempre lo mismo que el contenedor y se recorta con
   `clip-path: inset(... round)` (el radio no se deforma). Se anima el recorte con GSAP: full `back.out(1.4)` 0,45 s,
   lite `power3.out` 0,3 s, reduced salto directo. Primera colocación y resize sin animar. Sin `transition-all`.
   - Decisión: se pierden el borde y la sombra interior de la pill (versión plana, aprobada).
2. **Header que se oculta al bajar (< lg) + barra de progreso** (`Header.astro`, `Layout.astro`, `styles.css`):
   `data-hidden` por script mínimo (rAF, umbral 8 px, no se oculta con menú abierto, foco de teclado, final de página
   ni en los primeros ~2× su alto). Movimiento solo `transform`. Barra de 2 px con `animation-timeline: scroll()`
   (sin soporte: no se muestra). Token `--z-progress`.
   - Durante un scroll por ancla (`scrollToTarget`) el header se queda visible: `lenis.ts` marca
     `html[data-anchor-scroll]` y el script del header lo respeta (evita el hueco de 64 px sobre el título).
3. **Divisores que se dibujan** (`SectionDivider.astro`, `styles.css`): `scaleX(0→1)` desde el centro con
   `animation-timeline: view()` y `animation-range: entry 0% entry 60%`. Sin soporte / reduced: línea completa.
4. **Sobre mí, entrada escrita** (rehecha a petición del usuario tras revisar T4/T5; `about.ts` nuevo, `About.astro`,
   `global.css`, `styles.css`): misma coreografía que el Hero, disparada una vez al llegar a la sección
   (`ScrollTrigger once`, `top 60 %`; en móvil sobre el título, `top 85 %`).
   - Imagen con fundido de opacidad (sustituye la cortina de T5) y parallax ±4 % solo con puntero fino; marco idéntico
     en 390/768/1024/1440/1920; el DOM queda `.about-frame > img.about-img`.
   - Título (`char`, 1,1 s) y descripción (`word`, 2,1 s) escritos con un único cursor que salta de uno a otro.
   - Etiquetas una a una (pop como las redes del Hero, paso `min(0,12; 1,2/n)`) y después el botón CV con rebote.
   - Niveles: lite escribe el título y la descripción entra en bloque; reduced, solo fundidos. Sin JS todo visible;
     red de seguridad a los 4 s; limpieza al cambiar de tier. `about.js` carga en idle como chunk aparte (+1,5 KB gzip).
   - Se **retiró** la bio iluminada con scroll (`.illuminate`, `@property --p`) y la API `data-motion="pop"`.
   - Icono del botón CV: 3 px a la derecha en hover (solo puntero fino).
